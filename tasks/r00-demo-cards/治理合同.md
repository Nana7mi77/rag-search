# 需求治理合同: REQ-002

## 需求概述
Demo: 搜索结果以10张B站链接卡片展示，点击可定位到纪录片片段

## 目标
- 用户输入查询 → 系统返回10条结果
- 每条结果渲染为卡片：纪录片名 + 时间戳 + 字幕文本 + 占位截图
- 点击卡片 → 跳转B站视频页并定位到对应时间戳
- 截图使用SVG占位符（无真实视频文件）

## 非目标
- 不做真实视频截图抓取（无视频文件）
- 不做B站登录/OAuth
- 不做后端LLM生成
- 不做移动端适配

## 任务类型: New
## 风险等级: 低（新功能，不改现有核心逻辑）

## 候选范围
- `rag_search/web.py` - API + 前端HTML
- `rag_search/rag.py` - 搜索结果数据结构（可能需扩展）
- `rag_search/index.py` - Document/SearchHit（可能需加字段）

## 拆解（命中拆解规则: 主入口文件>=3, 多类改动）
