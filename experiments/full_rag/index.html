一、实验设计

实验 A 基线对照组

数据规模：500 条（采样）
Embedding：bge-small-en-v1.5
向量维度：384 维（英文模型）
特点：轻量英文模型，对中文语义理解弱

实验 B 全量中文组

数据规模：6071 条（全量）
Embedding：multilingual-e5-large
向量维度：1024 维（多语言模型）
特点：大模型 + 全物料，中文语义理解强

变量控制

两组实验使用完全相同的：BM25 引擎、知识图谱、测试查询、评估指标、RRF 融合参数。
唯一差异：数据规模（500 vs 6071）和 Embedding 模型（英文 384 维 vs 多语言 1024 维）。
这样可以准确归因效果提升的来源。

六、关键洞察

中文模型的威力

英文模型（bge-small-en）把"浮力在潜水艇中的应用"编码后，与中文字幕的向量距离很远（MRR=0）。

中文模型（multilingual-e5-large）理解了"浮力""潜水艇"的中文语义，正确命中（MRR=0.25）。

1024 维向量比 384 维能编码更多信息，多语言训练让中文不再是从英文"翻译"过来的二手语义。

全量数据的价值

BM25 从 0.733 → 0.769（+5%），看似不多，但这是因为 500 条采样已经覆盖了大部分关键词命中的场景。

全量 6071 条的价值更多体现在：
• 向量检索有更多候选文档可匹配
• "闪电是怎么形成的"从全军覆没到 BM25 命中 0.33
• Hybrid 融合的候选池更丰富，Hit@5 达到 0.933

图谱增强依然是核心差异化

"密度计的工作原理"：BM25 直接搜 = 0 分，BM25+KG = 1.00（完美命中）。KG 把"密度计"扩展为"浮力、密度、液体"，解决了用户查询与文档表述的语义鸿沟。

"自然光源有哪些"：BM25 = 0.20，BM25+KG = 1.00。KG 扩展"光源"为"太阳、蜡烛、灯泡"等具体实例。

无论使用什么 Embedding 模型，知识图谱增强始终带来稳定提升，这是项目的独特优势。

八、结论与建议

实验结论

  • 中文 Embedding 模型是必须的：英文模型处理中文内容效果极差（Vector MRR=0.3），中文多语言模型让效果提升 150%（MRR=0.75）
  • 全量数据有价值：6071 条 vs 500 条，各方法均有提升，向量检索受益最大
  • BM25+KG 仍然是最优单一方法：MRR=0.867，零外部依赖，延迟最低
  • Hybrid 召回率最高：Hit@5=0.933，适合对"找得到"要求最高的场景
  • 图谱增强是核心竞争力：无论哪种检索方式，KG 增强都能带来 10-70% 的稳定提升

生产部署建议

  • 推荐方案：BM25+KG+Hybrid 混合 — 用 BM25+KG 作为主召回，Hybrid 作为兜底补充
  • 向量检索定位：作为语义搜索的补充通道，必须使用中文 Embedding 模型
  • 图谱扩展优先级最高：持续完善知识图谱，比换模型更有效
  • 下一步优化方向：测试查询扩展（Query Expansion）、重排序（Reranker）、LLM 生成式回答
