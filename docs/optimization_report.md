## 一、项目背景与目标

### 1.1 业务场景

基于 BBC 纪录片《光的故事》(Light Fantastic) 等科普视频的中文字幕，构建 RAG 检索系统。用户提出自然语言问题（如"潜水艇如何上浮和下潜"），系统从 6,071 条字幕片段中找到最相关的回答。

### 1.2 核心目标

**在用 KG 和不用 KG 两种场景下，向量检索方案都能超越 BM25 基线。**

### 1.3 评估体系

| 指标 | 含义 | 计算方式 |
|------|------|----------|
| MRR | 平均倒数排名 | 第一个相关文档的排名倒数，15 条查询取均值 |
| Hit@3 | 前 3 召回率 | 前 3 个结果中包含相关文档的查询比例 |
| Hit@5 | 前 5 召回率 | 前 5 个结果中包含相关文档的查询比例 |

相关性判断：文档的 `title + text` 中包含查询的任何关键词（不区分大小写子串匹配）。

### 1.4 测试集

15 条查询，覆盖浮力/潜水艇、光学/光源、郑和宝船三大主题：

- bge-m3 纯文本向量已超越 BM25（0.800 > 0.769）

## 四、实验全记录

### 4.1 V1：文本表示改进 + RRF 权重探索（12 组）

**实验目标**：探索 RRF 融合权重、KG 融合方式、文本表示方案

**实验方法**：
- RRF (Reciprocal Rank Fusion) 融合公式：
  ```
  score(doc) = w_bm25 / (k + rank_bm25(doc)) + w_vec / (k + rank_vec(doc))
  ```
- BM25+KG 文本扩展：将 KG expansion 拼接到查询文本
- 不同权重组合：bm25_w ∈ {1.5, 2.0, 3.0}, vec_w ∈ {0.3, 0.5, 0.7, 1.0}
- 候选集大小：15（固定）

**完整结果**：

| 方法 | MRR | Hit@3 | Hit@5 | 备注 |
|------|-----|-------|-------|------|
| **RRF(bm25=3.0, vec=0.5, k=30)** | **0.889** | **0.933** | **0.933** | ⭐ V1 最优 |
| RRF(bm25=2.0, vec=0.5, k=30) | 0.889 | 0.933 | 0.933 | 并列最优 |
| RRF(bm25=3.0, vec=0.3, k=30) | 0.878 | 0.933 | 0.933 | |
| RRF(bm25=1.5, vec=0.5, k=30) | 0.867 | 0.867 | 0.933 | |
| BM25+KG (baseline) | 0.867 | 0.867 | 0.867 | |

**V1 结论**：
- RRF 融合（bm25 权重 3.0，vec 权重 0.5）MRR=0.889，首次超越 BM25+KG（0.867）
- BM25 权重应显著高于 Vec 权重（3:0.5 = 6:1），因为候选集仅 15 条时 BM25 更可靠
- MRR=0.889 成为新的天花板

### 4.3 V3：KG 术语提取 + Boost 策略（38 组）

**实验目标**：改进 KG 融合方式——不再拼接整段文本，而是提取 CJK 关键术语作为 BM25 boost

**核心创新**：

之前的 KG 用法是将整段 expansion 文本拼接到查询中，但这样会稀释语义信号。V3 改为：

1. 从 KG expansion 中提取 ≥2 字的中文术语（CJK 正则匹配）
2. 在 BM25 搜索时，如果文档包含这些术语，给予额外分数加成
3. BM25.search 新增 `boost_terms` 和 `boost_weight` 参数

```
BM25+Boost 计算流程：
  原始 BM25 分数 = Σ IDF(t) × TF(t, doc) / (TF(t, doc) + k1 × (1 - b + b × |doc|/avgdl))
  
  如果 doc 包含 boost_term:
    最终分数 = 原始 BM25 分数 × (1 + boost_weight)
```

**搜索空间**：
```

boost_weight ∈ {0.1, 0.2, 0.3, 0.5, 0.8, 1.0}

bm25_w ∈ {1.5, 2.0, 3.0}
vec_w ∈ {0.3, 0.5, 0.7, 1.0}
候选集 ∈ {15, 30, 50}
```

### 4.4 V4：查询扩展 + 大候选集 + WSF 突破（40 组）⭐

**实验目标**：突破 0.889 天花板

**核心创新**：

1. **候选集从 15 扩大到 50/80**：更多候选 = 融合时有更多机会找到正确文档
2. **Weighted Score Fusion (WSF)**：不再用排名融合，改用分数融合
3. **Max Fusion**：取两种分数的较大值
4. **KG 查询扩展**：将 KG 术语/别名拼接到查询，增强向量检索

**WSF 融合公式推导**：
```
给定两条检索系统的原始分数：
  s_bm25(doc) = BM25 原始分数
  s_vec(doc)  = 向量余弦相似度

归一化：
  s_bm25_norm(doc) = s_bm25(doc) / max(s_bm25)
  s_vec_norm(doc)  = s_vec(doc)  / max(s_vec)

加权融合：
  WSF_score(doc) = w_vec × s_vec_norm(doc) + w_bm25 × s_bm25_norm(doc)

当 w_vec = w_bm25 = 0.5 时，两条检索系统贡献相等。
```

**为什么 WSF 优于 RRF？**

```
RRF 只使用排名信息，丢失了分数差异：

  场景：Vec 返回 [A(0.95), B(0.94), C(0.93)]
        BM25 返回 [D(15.2), A(12.1), E(8.5)]

  RRF 看到的：A(rank1, rank2), B(rank2), C(rank3), D(rank1), E(rank3)
  → A 的 RRF 分数 = 1/(30+1) + 1/(30+2) = 0.063

  WSF 看到的：A(0.95/0.95 × 0.5 + 12.1/15.2 × 0.5) = 0.898
  → WSF 能区分 A 的向量分数极高但 BM25 分数中等的情况

  关键差异：当一方对某个文档非常有信心（分数远高于其他文档）时，
  WSF 能捕获这个信号，而 RRF 只看到"排名第1"。
```

**搜索空间**：
```

WSF vec_w ∈ {0.3, 0.5, 0.7}

RRF bm25_w ∈ {1.5, 2.0, 3.0}

```

### 4.5 V5：自适应融合 + 信任度回退（23 组）

**实验目标**：探索自适应策略，根据查询特征动态选择融合方式

**核心方法**：

1. **自适应信任（adaptive_trust）**：当一方置信度低时信任另一方
   ```
   if bm25_conf < threshold_low and vec_conf > threshold_high:
       score = vec_score  # 信任向量
   else:
       score = WSF(bm25, vec)  # 正常融合
   ```

2. **证据投票（evidence_vote）**：BM25 和 Vec 的 top-20 交集获得投票奖励

### 4.8 V8：Cross-Encoder 重排序（22 组）

**核心方法**：

使用 `cross-encoder/ms-marco-MiniLM-L-6-v2` 对候选文档进行精细重排序：

```python
from sentence_transformers import CrossEncoder
reranker = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2', max_length=512)

def rerank(query, candidate_ids, docs_list, reranker_model, top_n=5):
    pairs = [(query, f"{docs_list[idx].title} {docs_list[idx].text}") 
             for idx in candidate_ids]
    scores = reranker_model.predict(pairs)
    scored = list(zip(candidate_ids, scores.tolist()))
    scored.sort(key=lambda x: x[1], reverse=True)
    return scored[:top_n]
```

### 6.1 策略公式对比

```
│ RRF (Reciprocal Rank Fusion):                                       │
│   score(doc) = Σ w_i / (k + rank_i(doc))                           │

│                                                                     │
│ MAX (Max Fusion):                                                   │
│   score(doc) = max(w_i × s_i(doc) / max(s_i))                      │
```

### 10.2 推荐生产配置

```python
# 方案一：WSF（无 KG 场景，轻量级，最推荐）
def wsf_retrieve(query, candidates=50, vec_weight=0.5):
    """
    Weighted Score Fusion
    - 候选集：50
    - 向量权重：0.5
    - BM25 权重：0.5
    - MRR=0.900, Hit@3=1.000, Hit@5=1.000
    """
    bm25_docs = bm25_search(query, top_n=candidates)
    vec_docs = vec_search(query, top_n=candidates)
    
    # 归一化
    bm25_max = max(d.score for d in bm25_docs)
    vec_max = max(d.score for d in vec_docs)
    
    # 加权融合
    results = {}
    for doc in bm25_docs:
        results[doc.id] = (1 - vec_weight) * (doc.score / bm25_max)
    for doc in vec_docs:
        results[doc.id] = results.get(doc.id, 0) + vec_weight * (doc.score / vec_max)
    
    return sorted(results.items(), key=lambda x: x[1], reverse=True)

# 方案二：RRF（含 KG 场景，鲁棒性强）
def rrf_retrieve(query, candidates=80, k=30, vec_weight=1.5, bm25_weight=1.0):
    """
    Reciprocal Rank Fusion + KG Boost
    - 候选集：80
    - k=30, vec_w=1.5, bm25_w=1.0
    - MRR=0.900, Hit@3=0.933, Hit@5=0.933
    """
    kg_terms = extract_kg_terms(query)
    bm25_docs = bm25_search(query, top_n=candidates, boost_terms=kg_terms)
    vec_docs = vec_search(query, top_n=candidates)
    
    # RRF 融合
    results = {}
    for rank, doc in enumerate(bm25_docs):
        results[doc.id] = bm25_weight / (k + rank + 1)
    for rank, doc in enumerate(vec_docs):
        results[doc.id] = results.get(doc.id, 0) + vec_weight / (k + rank + 1)
    
    return sorted(results.items(), key=lambda x: x[1], reverse=True)

# 方案三：Rewrite+Vec+Rerank（V9 最优，需要 GPU 加速）
def rewrite_vec_rerank_retrieve(query, candidates=50, rewrites=None):
    """
    两阶段检索：Vec 召回 + 中文 Reranker 精排
    - 候选集：50
    - Reranker: BAAI/bge-reranker-v2-m3
    - MRR=0.907, Hit@3=0.933, Hit@5=1.000
    - 优势：Q9(闪电)完全修复，整体最优
    - 注意：推理速度慢（M1 MPS ~1.3 pairs/s），需要 GPU 加速
    """
    # Step 1: 查询改写（如果有）
    all_queries = [query]
    if rewrites:
        all_queries.extend(rewrites)
    
    # Step 2: 向量召回
    all_candidates = {}
    for q in all_queries:
        q_vec = embed_query(q)
        vec_res = vector_search(q_vec, doc_vecs, top_k=candidates)
        for idx, score in vec_res:
            all_candidates[idx] = max(all_candidates.get(idx, 0), score)
    
    # Step 3: 取 top-N 候选
    candidate_ids = sorted(all_candidates.keys(), 
                          key=lambda x: all_candidates[x], reverse=True)[:candidates]
    
    # Step 4: Reranker 精排
    reranker = CrossEncoder("BAAI/bge-reranker-v2-m3")
    pairs = [(query, docs[idx].text) for idx in candidate_ids]
    scores = reranker.predict(pairs)
    
    # Step 5: 按 reranker 分数排序
    scored = list(zip(candidate_ids, scores.tolist()))
    scored.sort(key=lambda x: x[1], reverse=True)
    
    return scored[:10]
```

## 十一、结论与展望

### 11.1 核心结论

1. **WSF 是最优轻量级融合策略**（无 KG 场景），MRR=0.900，Hit@3=1.000

5. **候选集大小是关键超参**：WSF 最优 50，RRF 最优 80
6. **中文 Cross-Encoder + 查询改写突破天花板**：V9 最优 MRR=0.907，Q9(闪电)完全修复
